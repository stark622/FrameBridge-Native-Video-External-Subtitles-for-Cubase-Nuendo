STEINBERG FILES
  No Steinberg DLL or EXE is distributed in this package. INSTALL.cmd temporarily
  replaces Components\videoengine.dll in the customer's local Cubase/Nuendo
  installation with the FrameBridge module and, where applicable, also replaces
  Components\MXFHandler\mxfhandler.dll. Before replacement it saves each exact
  original locally and binds its SHA-256 and host path in the installation state;
  UNINSTALL.cmd verifies that state before restoring the original. For Cubase 8/9,
  installation also makes verified local copies of the customer's existing
  videodecode.exe, videooutput.exe and videopreload.exe beside that host's saved
  engine, then removes its own copies on rollback. The customer's original helper
  files stay in Components. No original Steinberg binaries are included in or
  redistributed with the FrameBridge download.

  At run time FrameBridge works alongside the preserved original engine of the
  customer's installation. No Steinberg executable code is modified or patched.
