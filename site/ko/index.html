Beta 1 · Windows x64 · Cubase & Nuendo

다양한 비디오·자막 포맷 지원.
Cubase와 Nuendo의 기본 비디오 플레이어에서 바로.

FrameBridge는 Windows용 Cubase와 Nuendo의 내장 비디오 엔진을 확장합니다. 최신 비디오 포맷이 기본 비디오 트랙에서 열리고, 외부 자막 파일은 화면 위에 자동으로 표시됩니다. 트랜스코딩도, 자막을 영상에 입히는 작업도 필요 없습니다.

비디오 가이드 보기

포스터: 실제 Nuendo 프로젝트의 원본 스크린샷입니다. 위 영상은 Cubase 11 Pro에서 진행하는 짧은 비디오 가이드로, SRT 자막 파일과 함께 있는 MKV와 SDR로 표시되는 HDR MKV를 보여 줍니다. YouTube 확장판은 다양한 비디오 포맷과 자막 형식을 실시간으로 가져오는 모습을 편집 없이 한 번에 담았습니다.

설치하고, 닫고, 잊으세요

코덱 팩도, 별도의 비디오 플레이어도, 납품받을 때마다 하는 변환도 필요 없습니다.

1

INSTALL.cmd 실행

Cubase/Nuendo를 닫고 설치 프로그램을 실행하세요. 등록된 설치는 자동으로 찾아지며, 찾지 못하면 프로그램의 EXE 파일이나 폴더를 선택하면 됩니다.

2

비디오 가져오기

MKV, MOV, MP4, MXF, AVI 등이 기본 비디오 트랙에서 열리고 내장 비디오 플레이어에서 재생되며, 타임라인에는 썸네일도 표시됩니다.

3

자막은 저절로 나타납니다

자막 파일을 비디오와 같은 이름으로 같은 폴더에 두세요(film.mkv + film.srt). 자막이 화면 위에 표시되고, 파일을 수정하면 바로 반영됩니다.

주요 기능

더빙과 보이스오버, 포스트 프로덕션, 영상 음악 작업을 위해 만들었습니다.

  • Cubase/Nuendo 기본 비디오 트랙과 내장 비디오 플레이어에서 작동합니다.
  • 함께 제공되는 FFmpeg 라이브러리(LGPL)로 컨테이너와 코덱 지원을 확장합니다.
  • 외부 자막을 자동으로 불러와 화면 위에 표시합니다. 비디오 파일 자체는 절대 변경되지 않습니다.
  • 모든 자막 포맷이 하나의 깔끔하고 읽기 쉬운 모양으로 표시됩니다. 스타일 때문에 깨지는 일이 없습니다.
  • 블루레이 PGS/SUP와 DVD VobSub 이미지 자막은 Windows 내장 OCR로 텍스트로 읽어 들입니다.
  • 지원되는 HDR 소스의 HDR→SDR 변환을 육안으로 검증했습니다.
  • UNINSTALL.cmd는 검증된 백업에서 프로그램 원본 파일을 바이트 단위까지 그대로 복원합니다. 프로젝트, 환경 설정, 플러그인은 건드리지 않습니다.

인접 버전

비디오 엔진은 같은 제품 세대 안에서는 거의 바뀌지 않으므로 인접 버전에서도 작동할 가능성이 매우 높습니다. 설치 프로그램이 각 설치의 비디오 엔진을 직접 확인하여, 호환되는 설치는 설치 대상으로 표시하고 호환되지 않는 설치는 목록에 표시하지 않으며 아무것도 변경하지 않습니다. 작동을 보장하는 것은 아닙니다.

성능

무거운 4K 10비트 영상(HEVC Main10, H.264 High10)에는 충분한 성능의 CPU/GPU가 필요합니다. 오래된 PC에서는 비디오 썸네일을 끄고 1080p 이하의 H.264 8비트 작업용 사본을 사용하는 것을 권장합니다.

자세한 내용과 알려진 제한 사항: 호환성 안내(영문).

자주 묻는 질문

FrameBridge가 비디오 파일을 변경하나요?

아니요. 자막은 재생 중에 화면 위에 표시될 뿐이며, 비디오 파일과 자막 파일은 그대로 유지됩니다.

어떻게 제거하나요?

Cubase/Nuendo를 닫고 UNINSTALL.cmd를 실행하세요. 설치할 때 만든 검증된 백업에서 프로그램 원본 파일을 바이트 단위까지 그대로 복원합니다.

Steinberg 파일이 포함되어 있나요?

아니요. 패키지에는 Steinberg 파일이 전혀 포함되어 있지 않으며, 설치 프로그램은 사용자의 설치 파일만 다룹니다.

백신 프로그램이 경고를 표시합니다. 왜 그런가요?

FrameBridge는 새로운 소프트웨어로 아직 코드 서명이 되어 있지 않고, 설치 프로그램이 프로그램 DLL 하나를 교체하기 때문에 일부 휴리스틱 검사기가 이 패턴을 표시합니다. 릴리스 압축 파일은 VirusTotal에서 검사했습니다(보고서, 2026년 10월 31일 기준). 결과는 1/63으로, 엔진 하나의 일반적인 휴리스틱 탐지 1건뿐입니다. Microsoft Defender, Kaspersky, BitDefender, ESET, Malwarebytes, Sophos, Symantec 등 검사를 마친 나머지 엔진에서는 아무것도 탐지되지 않았습니다. 설치 프로그램은 네트워크에 접속하지 않으며, 정확한 복원을 위해 검증된 백업을 보관합니다.

릴리스 파일 SHA-256: c804d914c86e2abe7f05476455ae8efb447c6f2a74220bef515af9d266709e50

VST 플러그인인가요? Mac 버전이 있나요?

둘 다 아닙니다. FrameBridge는 플러그인이 아니라 Cubase와 Nuendo의 기본 비디오 엔진을 확장합니다. 따라서 비디오는 내장 비디오 플레이어에서 재생되며 프로젝트에 따로 불러올 것이 없습니다. Windows x64 전용입니다.

어떤 자막 파일을 불러오나요?

비디오와 같은 폴더에 있고 비디오와 이름이 같은 자막 파일입니다. 예: film.mkv + film.srt. VobSub는 두 파일이 한 쌍이므로 film.idx와 film.sub를 함께 두세요.

제 시스템에서 작동하지 않으면 어떻게 하나요?

구매 후 14일 이내에 stark622@ukr.net로 메일을 보내 주세요. FrameBridge가 사용 중인 Cubase 또는 Nuendo에 설치되지 않거나 작동하지 않으면 전액 환불해 드립니다.

Cubase나 Nuendo를 업데이트해도 작동하나요?

FrameBridge는 위에 나열된 빌드(Cubase 및 Nuendo 15.0.30까지)에서 검증되었으며, 버전 15 전체에서 작동하도록 만들어졌습니다. 설치 프로그램이 각 설치의 비디오 엔진을 직접 확인합니다. 버전 15 안에서 업데이트한 후 FrameBridge가 작동하지 않으면 INSTALL.cmd를 다시 실행하세요. 업데이트로 프로그램 파일이 교체되었을 수 있습니다. Cubase 또는 Nuendo 16 같은 새 메이저 버전은 비디오 엔진이 바뀔 수 있으며 이번 베타의 지원 대상이 아닙니다.
