다양한 비디오·자막 포맷 지원.
Cubase와 Nuendo의 기본 비디오 플레이어에서 바로.

FrameBridge는 Windows용 Cubase와 Nuendo의 내장 비디오 엔진을 확장합니다. 최신 비디오 포맷이 기본 비디오 트랙에서 열리고, 외부 자막 파일은 화면 위에 자동으로 표시됩니다. 트랜스코딩도, 자막을 영상에 입히는 작업도 필요 없습니다.

비디오 가이드 보기

위 영상은 Cubase 11 Pro에서 진행하는 짧은 비디오 가이드로, SRT 자막 파일과 함께 있는 MKV와 SDR로 표시되는 HDR MKV를 보여 줍니다. YouTube 확장판은 편집 없이 한 번에 실시간으로 가져오는 모습을 담았습니다: MKV(HEVC 4K 10비트, HDR 포함), OGV(Theora), MXF(DNxHR 4K), MOV(ProRes 4444 4K)와 여러 자막 형식.

설치하고, 닫고, 잊으세요

코덱 팩도, 별도의 비디오 플레이어도, 납품받을 때마다 하는 변환도 필요 없습니다.

1

INSTALL.cmd 실행

Cubase/Nuendo를 닫고 설치 프로그램을 실행하세요. 등록된 설치는 자동으로 찾아지며, 찾지 못하면 프로그램의 EXE 파일이나 폴더를 선택하면 됩니다.

2

비디오 가져오기

MKV, MOV, MP4, MXF, AVI 등이 기본 비디오 트랙에서 열리고 내장 비디오 플레이어에서 재생되며, 타임라인에는 썸네일도 표시됩니다.

3

자막은 저절로 나타납니다

자막 파일을 비디오 옆에 같은 이름으로 두세요(film.mkv + film.srt). 화면 위에 표시되며, 수정 사항은 다시 가져오지 않아도 바로 반영됩니다.

주요 기능

더빙과 보이스오버, 포스트 프로덕션, 그리고 영화와 게임 음악을 쓰는 작곡가를 위해 만들었습니다.

자주 묻는 질문

Cubase나 Nuendo에서 “Invalid or not supported file!”이라고 나옵니다. FrameBridge로 열 수 있나요?

대부분 가능합니다. 이 메시지는 기본 비디오 엔진이 파일의 컨테이너, 코덱 또는 프레임 레이트를 처리하지 못할 때 표시됩니다. 예를 들어 MKV, WebM, MXF, iPhone 같은 스마트폰으로 촬영한 HEVC, 가변 프레임 레이트 비디오 등입니다. FrameBridge는 자체 디코더로 이러한 파일을 읽습니다. 검증된 포맷은 위에 나와 있습니다. 그래도 파일이 열리지 않으면 14일 이내에 전액 환불해 드립니다.

File → Import → Video File로 가져오는데 목록에 MKV가 보이지 않아요

가져오기 창 아래쪽 파일 형식에서 “Any Type (*.*)”을 선택하면 모든 파일이 표시됩니다. 저희는 모든 테스트를 파일을 폴더에서 프로젝트로 바로 끌어다 놓는 방식으로 했습니다. 이 방법이 가장 쉽고, 가져오기 창으로도 동작합니다.

FrameBridge가 비디오 파일을 변경하나요?

아니요. 자막은 재생 중에 화면 위에 표시될 뿐이며, 비디오 파일과 자막 파일은 그대로 유지됩니다. Cubase의 Export Video로 영상을 저장하면 자막이 내보낸 영상에 입혀진다는 점에 유의하세요(Cubase 15에서 확인). 깨끗한 화면이 필요하면 내보내기 전에 자막 파일 이름을 바꾸세요.

설치 프로그램이 프로그램 파일을 교체해도 안전한가요? 백신이 경고하면요?

설치 프로그램은 정확한 복원을 위해 만들어졌습니다. 교체하기 전에 원본 파일을 검증해 보관하고, UNINSTALL.cmd가 바이트 단위까지 그대로 되돌립니다. 네트워크 접속, 서비스, 자동 실행이 없으며 패키지에 Steinberg 파일은 하나도 없습니다. VirusTotal: 0/61(보고서, 2026년 11월 26일 기준). 파일에 아직 디지털 서명이 없어 휴리스틱 검사기가 DLL 교체에 반응할 수는 있지만, 이는 동작 패턴에 대한 반응일 뿐 위협이 발견된 것이 아닙니다. PC에서 정확히 무엇이 바뀌는지와 직접 확인하는 방법: SECURITY.md(영어)

VST 플러그인인가요? Mac 버전이 있나요?

둘 다 아닙니다. FrameBridge는 플러그인이 아니라 Cubase와 Nuendo의 기본 비디오 엔진을 확장합니다. 따라서 비디오는 내장 비디오 플레이어에서 재생되며, 플러그인 슬롯도, 프로젝트마다 불러올 것도, MTC 동기화도 필요 없습니다. Windows x64 전용입니다.

Cubase나 Nuendo를 업데이트해도 작동하나요?

FrameBridge는 위에 나열된 빌드(Cubase 16.0.5 및 Nuendo 15.0.40까지)에서 검증되었습니다. 새 메이저 버전에서 비디오 엔진이 바뀌면 설치 프로그램은 그 설치를 제안하지 않고 아무것도 변경하지 않습니다. Cubase나 Nuendo를 업데이트한 뒤에는 INSTALL.cmd를 다시 실행하기만 하면 됩니다. Cubase나 Nuendo 업데이트 후 FrameBridge가 작동하지 않으면 지원팀에 문의하세요.

어떤 더빙 대본 형식을 읽을 수 있나요?

대본 파일 이름을 영상과 같게 하세요 (film.mkv + film.docx). 같은 이름의 일반 자막 파일이 있으면 그것이 우선합니다. DOCX, DOC, XLSX, XLS, PDF, RTF, ODT, ODS, TXT, CSV — 머리글이 있거나 없는 표, 시작 시간만 있는 대본, 테이크 형식. 위의 구매 전에 확인하세요에 대본을 끌어다 놓으면 FrameBridge가 어떻게 읽는지 바로 보입니다.
