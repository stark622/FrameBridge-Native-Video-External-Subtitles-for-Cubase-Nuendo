Install, close, forget

No codec packs, no separate video player, no conversion of every new delivery.

1

Run INSTALL.cmd

Close Cubase/Nuendo and run the installer. Registered installations are found automatically; otherwise pick the program's EXE or folder.

2

Import your video

MKV, MOV, MP4, MXF, AVI and more open on the native video track and play in the built-in Video Player, with thumbnails on the timeline (except Cubase 10.5–11 and Nuendo 10).

3

Subtitles appear by themselves

Put the subtitle file next to the video with the same name (film.mkv + film.srt). It is shown over the picture; edits are picked up live — even a file added or renamed after import, no re-import needed.

What you get

Built for dubbing and voice-over, post-production and scoring to picture.

  • Works with the native Cubase/Nuendo video track and built-in Video Player.
  • Extended container and codec support through packaged FFmpeg libraries (LGPL).
  • External subtitles are loaded automatically and shown over the picture. The video file itself is never changed.
  • Every subtitle format is drawn in one clean, readable look — no styling surprises.

  • Audio comes in with the standard “Extract Audio From Video” — also from MKV and other files Cubase and Nuendo can't open on their own.
  • UNINSTALL.cmd restores the original program files from a verified backup, byte for byte. Projects, preferences and plug-ins are not touched.

Nearby builds

The video engine rarely changes within one product generation, so nearby builds very likely work too. The installer checks the video engine of each installation itself: a compatible one is offered, an incompatible one is not listed and nothing is changed. This is not a guarantee.

Performance

Heavy 4K 10-bit video (HEVC Main10, H.264 High10) needs a capable CPU/GPU. On older PCs, switching off video thumbnails and using H.264 8-bit working copies up to 1080p is recommended.

FAQ

Cubase or Nuendo says “Invalid or not supported file!” — will FrameBridge open the video?

Often, yes. Cubase and Nuendo show this message when their built-in video engine cannot handle the file’s container, codec or frame rate — for example MKV, WebM, MXF, HEVC from phones such as the iPhone, or video with a variable frame rate. FrameBridge reads such files with its own decoder; the verified formats are listed above. If your file still does not open, you get a full refund within 14 days.

Does FrameBridge change my video files?

No. Subtitles are displayed over the picture at playback time; the video file and the subtitle file stay exactly as they are. If you save a video with Cubase’s Export Video, keep in mind that the subtitles are burned into the exported file (checked in Cubase 15); rename the subtitle file before exporting if you need a clean picture.

How do I remove it?

Close Cubase/Nuendo and run UNINSTALL.cmd. It restores the original program files from the verified backup made during installation, byte for byte.

Does it include any Steinberg files?

No. No Steinberg file is shipped in the package; the installer works only with the files of your own installation.

My antivirus shows a warning. Why?

FrameBridge is new and its files are not code-signed yet, and the installer replaces one program DLL — some heuristic scanners flag that pattern. The release archive is checked on VirusTotal (report, as of 31 October 2026): 1/63 — a single generic heuristic from one engine; Microsoft Defender, Kaspersky, BitDefender, ESET, Malwarebytes, Sophos, Symantec and the other completed engines report no detection. The installer has no network activity and keeps a verified backup for exact rollback. What the installer changes on your PC and how to check it yourself: SECURITY.md (English)

Is it a VST plugin? Is there a Mac version?

No to both. FrameBridge is not a plugin: it extends the native video engine of Cubase and Nuendo, so video plays in the built-in Video Player — no plug-in slot, nothing to load in each project, no MTC sync. It runs on Windows x64 only.

Which subtitle file is picked up?

A subtitle file in the same folder with the same name as the video, for example film.mkv + film.srt. VobSub is a pair: keep film.idx and film.sub together.

What if it doesn't work on my system?

Write to stark622@ukr.net within 14 days of purchase. If FrameBridge does not install or work with your Cubase or Nuendo, you get a full refund.

Will it work after a Cubase or Nuendo update?

FrameBridge is verified with the builds listed above, up to Cubase and Nuendo 15.0.30, and will very likely keep working through version 15, though this is not guaranteed. Cubase 16 support is in closed beta: it already works in testing and will come with the next update. Nuendo 16 and other new major versions may change the video engine; using FrameBridge with them is at your own risk. To update Cubase or Nuendo, run UNINSTALL.cmd first, then install the update, then run INSTALL.cmd again. If FrameBridge stops working after an update, write to support.
