Install, close, forget

No codec packs, no separate video player, no conversion of every new delivery.

1

Run INSTALL.cmd

Close Cubase/Nuendo and run the installer. Registered installations are found automatically; otherwise pick the program's EXE or folder.

2

Import your video

MKV, MOV, MP4, MXF, AVI and more open on the native video track and play in the built-in Video Player, with thumbnails on the timeline.

3

Subtitles appear by themselves

Put the subtitle file next to the video with the same name (film.mkv + film.srt). It is shown over the picture, and edits are picked up live without re-import.

FAQ

Cubase or Nuendo says “Invalid or not supported file!” — will FrameBridge open the video?

Often, yes. Cubase and Nuendo show this message when their built-in video engine cannot handle the file’s container, codec or frame rate — for example MKV, WebM, MXF, HEVC from phones such as the iPhone, or video with a variable frame rate. FrameBridge reads such files with its own decoder; the verified formats are listed above. If your file still does not open, you get a full refund within 14 days.

Does FrameBridge change my video files?

No. Subtitles are displayed over the picture at playback time; the video file and the subtitle file stay exactly as they are. If you save a video with Cubase’s Export Video, keep in mind that the subtitles are burned into the exported video (checked in Cubase 15); rename the subtitle file before exporting if you need a clean picture.

Is it safe that the installer replaces a program file? What if my antivirus warns?

The installer is built for exact rollback: the original file is checked and saved before it is replaced, and UNINSTALL.cmd puts it back byte for byte. No network access, no services, no autostart, and no Steinberg file in the package. VirusTotal: 0/61 (report, 14 November 2026). The files are not code-signed yet, so a heuristic scanner may still react to the DLL replacement — a reaction to the pattern, not a found threat. Is it a VST plugin? Is there a Mac version?

No to both. FrameBridge is not a plugin: it extends the native video engine of Cubase and Nuendo, so video plays in the built-in Video Player — no plug-in slot, nothing to load in each project, no MTC sync. It runs on Windows x64 only.

Will it work after a Cubase or Nuendo update?

FrameBridge is verified with the builds listed above, up to Cubase 16.0.5 and Nuendo 15.0.30. A new major version may change the video engine — then the installer simply does not offer that installation and changes nothing. After updating Cubase or Nuendo, just run INSTALL.cmd again. If FrameBridge stops working after you update your Cubase or Nuendo, write to support.

Which dubbing script layouts are read?

Name the script like the video (film.mkv + film.docx); an ordinary subtitle file with the same name takes priority. DOCX, XLSX, PDF, TXT, CSV and more. Drop your script into Check before you buy above: it shows at once whether the current version of FrameBridge reads it and whether the next update (being tested) does.
