Cubase と Nuendo 標準のビデオプレーヤーでそのまま。

インストールしたら、あとは忘れるだけ

コーデックパックも、別のビデオプレーヤーも、納品のたびの変換も不要です。

1

INSTALL.cmd を実行

Cubase/Nuendo を終了してインストーラーを実行します。登録済みのインストールは自動で見つかります。見つからない場合は、プログラムの EXE またはフォルダーを選択してください。

2

ビデオを読み込む

MKV、MOV、MP4、MXF、AVI などが標準のビデオトラックで開き、内蔵のビデオプレーヤーで再生されます。タイムラインにはサムネイルも表示されます。

3

字幕は自動で表示

字幕ファイルをビデオと同じ名前で隣に置きます（film.mkv + film.srt）。映像の上に表示され、編集は読み込み直しなしでその場で反映されます。

吹き替え・ナレーション、ポストプロダクション、そして映画やゲームの音楽を書く作曲家のために。

よくある質問

Cubase や Nuendo で「形式が不適切であるか、対応していないファイルです。」と表示されます。FrameBridge なら開けますか？

多くの場合、開けます。このメッセージは、標準のビデオエンジンがファイルのコンテナ、コーデック、フレームレートに対応できないときに表示されます。たとえば MKV、WebM、MXF、iPhone などのスマートフォンで撮影した HEVC、可変フレームレートのビデオです。FrameBridge は独自のデコーダーでこれらのファイルを読み込みます。検証済みのフォーマットは上記のとおりです。それでもファイルが開けない場合は、14日以内なら全額返金します。

FrameBridge はビデオファイルを変更しますか？

いいえ。字幕は再生時に映像の上に表示されるだけで、ビデオファイルも字幕ファイルもそのまま変わりません。 Cubase の Export Video で動画を保存する場合、字幕は書き出した動画に焼き込まれる点に注意してください（Cubase 15 で確認）。字幕なしの映像が必要なら、書き出し前に字幕ファイルの名前を変更してください。

インストーラーがプログラムのファイルを置き換えても安全ですか？ウイルス対策ソフトが警告したら？

インストーラーは元どおりに戻せるように作られています。置き換える前に元のファイルを検証して保存し、UNINSTALL.cmd でバイト単位まで同じ状態に戻します。ネットワーク接続、サービス、自動起動はなく、パッケージに Steinberg のファイルは一切含まれません。VirusTotal：0/61（レポート、2026 年 11 月 14 日時点）。ファイルにはまだデジタル署名がないため、ヒューリスティック型のスキャナーが DLL の置き換えに反応することはありますが、これは手順のパターンへの反応であり、脅威が見つかったわけではありません。PC で何が変わるか、ご自身での確認方法は SECURITY.md（英語）をご覧ください。

VST プラグインですか？Mac 版はありますか？

どちらもいいえです。FrameBridge はプラグインではなく、Cubase と Nuendo 標準のビデオエンジンを拡張します。そのため、ビデオは内蔵のビデオプレーヤーで再生されます。プラグインスロットは不要で、プロジェクトごとに何かを読み込む必要も、MTC 同期も要りません。Windows x64 専用です。

Cubase や Nuendo をアップデートしても動作しますか？

FrameBridge は上記のビルド（Cubase 16.0.5 / Nuendo 15.0.30 まで）で検証済みです。新しいメジャーバージョンでビデオエンジンが変わった場合、インストーラーはそのインストールを候補に出さず、何も変更しません。Cubase / Nuendo をアップデートしたら、もう一度 INSTALL.cmd を実行するだけです。Cubase / Nuendo のアップデート後に FrameBridge が動作しなくなった場合は、サポートまでご連絡ください。

どの形式の吹き替え台本が読み込めますか？

台本は動画と同じ名前にします（film.mkv + film.docx）。同じ名前の通常の字幕ファイルがあればそちらが優先されます。
DOCX — 見出し行のある表：Start、End、Text（Role と No. は任意。In / Out、Subtitle、Speaker や Начало / Конец / Текст / Роль も可）。1 行 = 1 セリフ。
XLSX — 最初のシートに同じ列。時刻は文字列または Excel の時刻。
CSV — 見出し Начало;Конец;Текст（+ Роль）、区切りは ; 、, またはタブ。英語の見出しの CSV はこのベータでは認識されません。XLSX で保存してください。
TXT — 1 行に 1 セリフ：00:00:01,000 - 00:00:03,500 Anna: …。先頭に Начало - Конец - Текст の行を入れてください。
PDF — No / Start / End / Role / Text の単純なテキスト表、または TXT と同じ行のみ。ブラウザや Word から印刷した PDF は通常読み込めません。DOCX、XLSX、TXT を使ってください。
時刻 — ミリ秒付きの hh:mm:ss,mmm。各セリフに開始と終了が必要。フレーム（hh:mm:ss:ff）はファイルにフレームレート（例「25 fps」）がある場合のみ（XLSX は不可）。
読み込めないもの — 開始時刻のみ、mm:ss、ミリ秒なしの時刻、タイムコードの下の行にあるテキスト、表のない DOCX、.doc / .rtf / .odt、スキャンした PDF。
